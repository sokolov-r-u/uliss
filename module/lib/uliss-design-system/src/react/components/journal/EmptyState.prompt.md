Every empty screen in Uliss. Describes the future, not the lack.

```jsx
<EmptyState
  title="Nothing written down yet"
  body="Talk to Uliss for a while. When a thought is worth keeping, it writes the note for you — you never have to."
  action="Start a chat" />
```

- Title: serif, `text-wrap: balance`, sentence case, no trailing period.
- Body: reading scale, `--text-muted`, two sentences at most.
- One action, or none — an empty Sky has nothing to press, and that is allowed.
- On tablet/desktop keep the rail visible and centre this column at max-width 460 (compact) / 520.
