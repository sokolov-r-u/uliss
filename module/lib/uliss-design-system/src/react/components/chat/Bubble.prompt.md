```jsx
<Bubble role="uliss">You have come back to this thought three times.</Bubble>
```

- 20px between turns; the user's turn caps at 84% width.
- **Never label the user.** Never fill either side. Never round.
- Body type must stay on the reading tokens — hardcoding a px size here breaks Settings › Text size.
